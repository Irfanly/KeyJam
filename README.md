# KeyJam

**KeyJam** is a musician-focused music and chord analysis platform built with the MERN stack. It helps musicians analyze their song compositions and offers AI-powered suggestions to improve creativity and workflow.

## Features

- **AI-Powered Chord Studio:** Generate and edit song chords seamlessly using the Gemini API.  
- **Digital Chord Sheet Library:** Organize your songs with an intuitive digital chord sheet library for easy revisiting and management.  
- **Song Analysis:** Gain insights and suggestions on your compositions to enhance your music creation process.

## Lessons

KeyJam also includes a **Lessons** section designed to help musicians learn and improve their skills:  
- Explore a **Guitar Chord Library** with common and advanced chord charts.  
- Learn the theory behind chords and progressions to enhance your understanding of music composition.  
- Interactive tutorials and examples to practice and apply new skills.

## Tech Stack

- **MongoDB** – Database for storing songs and chord sheets  
- **Express.js** – Backend API framework  
- **React.js** – Frontend UI  
- **Node.js** – Server runtime  
- **Gemini API** – AI-powered chord generation and editing
